# AJZIO Brand Standard

## Core identity
- Brand: AJZIO
- Descriptor: Store
- Positioning line: Considered tech for everyday life.
- Visual character: calm, practical, considered, modern, dependable.

## Official color palette
Use these consistently across the website, social profiles, documents, and promotional graphics.

| Role | Name | HEX |
|---|---|---|
| Primary accent | AJZIO Sage | `#B4C49A` |
| Secondary accent | Deep Sage | `#879A6E` |
| Main background | Forest Charcoal | `#171D19` |
| Deep background | Night Forest | `#121713` |
| Surface | Moss Charcoal | `#202823` |
| Raised surface | Olive Slate | `#27312B` |
| Main text | Soft Ivory | `#E5E4D9` |
| Muted text | Sage Grey | `#929B90` |
| Borders | Forest Line | `#39443C` |

Avoid pure white, neon green, and unrelated gold/bronze accents. Keep sage as the recognizable brand accent; use semantic red only for genuine errors or destructive actions.

## Logo assets
- `static/logo.svg` — horizontal wordmark for website headers and footers.
- `static/icon.svg` — square brand icon for social avatars and app tiles.
- `static/favicon.svg` — browser tab icon.

Use SVG wherever possible so the mark stays sharp at every size. Leave clear space around the mark equal to the width of the small sage dot. Do not stretch, add 3D effects, add shadows, or recolor the logo outside the palette.
